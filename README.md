# 📚 Library System

Sistema de gerenciamento de livraria desenvolvido em **Java**, focado na aplicação de conceitos de **Programação Orientada a Objetos (POO)**. O projeto permite o gerenciamento de autores e livros, listagem de obras disponíveis e realização de empréstimos com cálculo automático de prazos.

---

### 🚀 Funcionalidades
- 📝 Cadastro organizado de autores e livros.
- 📋 Listagem inteligente de títulos disponíveis.
- ⏳ Realização de empréstimos com cálculo automático de prazo (40 dias).
- 🛡️ Tratamento de erros e validação de entrada de dados.
- 💻 Interface intuitiva via console.

---

### 🛠️ Tecnologias Utilizadas
- **Linguagem:** Java ☕
- **Manipulação de Datas:** `java.time` (LocalDate, DateTimeFormatter) 📅
- **Estrutura de Dados:** `java.util` (List, ArrayList) 📦

---

### 🎓 Aprendizados
Este projeto foi fundamental para consolidar conceitos como:
- 📂 **Estruturação em pacotes:** Organização profissional (Model, Service, Util, Application).
- 🧩 **POO:** Encapsulamento, construtores e polimorfismo.
- 🔄 **Fluxo de controle:** Loops, condicionais e tratamento de exceções (try-catch).
- 💾 **Gestão de estado:** Controle de disponibilidade de itens e persistência em listas.
